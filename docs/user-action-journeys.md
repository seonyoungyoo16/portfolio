# 사용자 행동과 처리 흐름 연결

사용자 요청: 왼쪽을 일반 사용자가 순서대로 조작할 수 있게 통일하고, 행동과 3D 경로·상태·실제 소스 매핑을 함께 검증한다.

ALPEN: A=공통 사용자 체험·프로젝트별 단계·경로/소스 감사·브라우저 검증·배포, L=구현 50분/검증 15분 블록, P=통합 여유 30%, E=기본 행동과 소스 대응 우선, N=아래 결과 갱신. 계획 시간이며 실제 실행 시간과 구분한다.

| 범위 | 진행 |
|---|---|
| 공통 조작 | `LabWorkbench` 사용자 체험/직접 실험 분리, `ActionJourney` 번호 순서·현재 행동·결과·다음 행동, 재생 완료 버튼 구현 중 |
| 로그인 | 로그인 → 내 정보 → 브라우저 재방문(쿠키 제거 후 복원) → 로그아웃. 동일 모델을 순차 실행하고 프레임을 합친다. |
| 회원가입 | 메일 요청 후 별도 작업자 발송 → 링크 GET → 확인 POST → 가입 확정. SSO 연결은 기존 로그인 → 외부 소유 확인 → 명시적 연결. |
| 결제 | 주문 → 결제 수단 인증 → 승인 → 부분/전액 취소. 장애·중복 요청은 직접 실험 화면. |
| 채팅 | 두 참가자 입장 → 전송 → B 오프라인 중 전송 → B 재접속 대화 복구. 빠른 완료도 모든 상태 단계를 거친다. |
| 경로 감사 | `auth-trace.ts`에 실제 소스별 처리 경계 명시. 로컬 행동·서버 내부·저장소 왕복·HTTP 응답·응답 유실 구분. |
| 소스 감사 | 브라우저 내부/환경 변경을 Java 실행처럼 표시하지 않는다. 해당 로컬 모델 분기를 고정 커밋에서 추출해 별도 연결 예정. 백엔드 소스 30/27/37/114개 고정 해시 검증 유지. |
| 검증·배포 | 기본 사용자 여정의 브라우저 검사, 기존 실험 회귀, 모든 경로의 유효 연결·소스 문장 검증, 모바일 및 공개 배포 확인 예정. |

현재 공개 사이트는 이전 흐름 우선 UI(source `6c864c6`, Pages `df9852f`)이고, 새 사용자 여정은 로컬 구현 중이다. 실제 백엔드 I/O와 공개 브라우저 시뮬레이션은 구분한다.
